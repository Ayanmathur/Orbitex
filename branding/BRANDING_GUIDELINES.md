## 🚀 Logo Variants & Usage Guidelines

### 1. Primary Logo (`primary-logo.svg` / `.png`)
- **Use for**: Main website headers, primary app navigation, brand collateral, marketing banners.
- **Composition**: Horizontal layout with Orbit Rocket-Bird emblem on the left and ORBITEX wordmark on the right.

### 2. Vertical Up Logo (`vertical-up-logo.svg` / `.png`)
- **Use for**: Mobile splash screens, social media profile avatars, vertical banners, posters, centered hero sections.
- **Composition**: Stacked layout with Icon mark on top and ORBITEX wordmark below.

### 3. Vertical Down Logo (`vertical-down-logo.svg` / `.png`)
- **Use for**: Alternative vertical layouts, app footers, card badges, specialized packaging.
- **Composition**: Stacked layout with ORBITEX wordmark on top and Icon mark below.

### 4. Monochrome Logo (`monochrome-logo.svg` / `.png`)
- **Use for**: Print documents, single-color/grayscale materials, dark metallic themes, corporate reports.
- **Composition**: Horizontal layout rendered in polished silver/grey metallic tone.

### 5. Word Only Logo (`word-only-logo.svg` / `.png`)
- **Use for**: Compact header spaces, inline text branding, legal/document headers.
- **Composition**: Standalone ORBITEX typography mark.

### 6. Icon Only Logo (`icon-only-logo.svg` / `.png`)
- **Use for**: App launcher icons, favicon, social media avatars, watermarks, button badges.
- **Composition**: Standalone Orbit Rocket-Bird emblem.

### 7. Favicon & App Icon Suite (`favicon/`)
- **Use for**: Browser tabs, mobile web apps (PWA), Apple iOS home screen, Android app icons.
- **Integration**:
```html
<link rel="icon" type="image/x-icon" href="branding/favicon/favicon.ico">
<link rel="icon" type="image/png" sizes="32x32" href="branding/favicon/favicon-32x32.png">
<link rel="icon" type="image/svg+xml" href="branding/favicon/favicon.svg">
<link rel="apple-touch-icon" sizes="180x180" href="branding/favicon/apple-touch-icon.png">
```
